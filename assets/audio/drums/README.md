# Drum samples

本目录的鼓组音色选自 [SM Drums](https://github.com/sfzinstruments/SMDrums)，
原始采样由 Scott McLean、Tod Stillwell 和 Suleiman Ali 制作。

原作者在
[SM Drums 发布说明](https://gearspace.com/board/samples-presets-profiles-and-services/992680-new-free-drum-samples-website-sm-drums.html)
中声明，网站内容可供任何人免费、免版税用于任何用途。

为了控制应用体积，本项目没有引入完整的 3.7GB 采样库，只为每种鼓件选择了一个
立体声、中高力度 WAV 样本：
